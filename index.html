🚀 Getting Started

Clone the repository:

git clone https://github.com/Pyrothrottler/phishing_attack.git
cd phishing_attack

Install dependencies:

pip install pandas numpy scipy scikit-learn joblib matplotlib streamlit

Train the models:

python Phishing_project_CSE_35.py
python retrain_with_url_features.py

Launch the web app:

streamlit run phishing_web_app_dashboard_v2.py

🧠 How It Works

  • Data: Merges the UCI Phishing Dataset (ARFF, ~30 heuristic features) with a Kaggle URL-feature dataset, standardizing column names and converting labels to binary (0 = Legitimate, 1 = Phishing).
  • Feature Engineering: Extracts URL characteristics such as length, dot/dash counts, subdomain depth, suspicious TLDs, login keywords, HTTPS presence, and more.
  • Models: Logistic Regression and Random Forest classifiers are trained and evaluated on accuracy, precision, recall, and F1-score.
  • Deployment: The best model powers a Streamlit dashboard where users can test single URLs in real time or upload a CSV for batch prediction, complete with a live phishing/legitimate pie-chart dashboard.
